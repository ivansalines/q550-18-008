# v18.49u — Physical return closure: decision rules

1. Never force end-state matching by a geometric connector or a reverse traversal of recorded data. The external velocity flip **is a declared intervention**, not endogenous time reversal.
2. Do **not** optimize next to the turnaround where the imposed flip makes an artificial tautological match. Forward anchor s in [0.30,0.85]; return time t=r+q with q in [0.10,0.96]. Report domain boundaries.
3. Optimize separately three measures: configuration, reversed velocity, and combined full state. The minima do not have to coincide; do not claim they do.
4. Evaluate actual original mechanical energy and full integrated ledger, not assumed energy conservation. For exact closure demand the predefined tolerances of all gates at the SAME section.
5. The wrapped angular phase is not the lifted phase. Report unwrapped Theta turns separately and optionally require phase-lift tolerance.
6. Evaluate 10D common-initial-frame projectors only for top candidates, composing both original tangent propagators with the exact external velocity-flip Jacobian.
7. If a spectral projector is absent/unresolved, classification is NOT a physical closure. Original rank-3 triad = eigenprojectors indices [5,6,7] (zero-based).
8. A finite unsuccessful scan means NO PHYSICAL CLOSURE **IN THE EXPLORED DOMAIN**; it is neither a global impossibility theorem nor evidence of material hysteresis.
9. A numerical closure candidate is not a material-memory certificate. Test refinement, perturbation, orientation and physical mechanism in a separate audit.
