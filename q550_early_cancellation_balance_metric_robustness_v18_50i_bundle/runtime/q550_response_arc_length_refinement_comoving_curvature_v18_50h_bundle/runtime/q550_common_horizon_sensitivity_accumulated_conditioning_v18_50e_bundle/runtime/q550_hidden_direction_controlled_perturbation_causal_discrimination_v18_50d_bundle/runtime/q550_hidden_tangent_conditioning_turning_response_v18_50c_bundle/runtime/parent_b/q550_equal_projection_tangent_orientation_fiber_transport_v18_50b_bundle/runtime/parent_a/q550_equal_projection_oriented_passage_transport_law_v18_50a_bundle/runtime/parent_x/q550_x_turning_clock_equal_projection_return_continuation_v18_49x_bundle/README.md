# Q550 v18.49x — X-Turning Clock & Equal-Projection Return Continuation Audit

This executable audit continues the authentic **v18.49w** in-ramp trajectory analysis. It finds actual turning roots of the projected coordinate `x`, compares them to the *prescribed* drive zero, and locates later exact returns to the same `x` value on the same 11D trajectory. It measures the unequal posture, radial locus and gauge-invariant triad projector distance at those events.

The **clock is not frozen**: the event positions are solved independently for each ramp and reported both in model coordinate `xi` and normalized ramp fraction `sigma`. Neither is asserted to be universal physical time.

## Run

```bash
cd /root/elab1/hysteresis
unzip q550_x_turning_clock_equal_projection_return_continuation_v18_49x_bundle.zip
cd q550_x_turning_clock_equal_projection_return_continuation_v18_49x_bundle
bash run_on_server.sh 2>&1 | tee v18_49x_server.log
```

To run one authentic regression quickly: `python3 scripts/run_audit.py --smoke --fail-fast` (the plotting scripts require a full run). CLI options include `--ramps 0.12 0.18 0.24 0.327375 0.5`, `--kind both|original|autonomous`, `--anchors .05 .10 .15 .20`, `--root-scan 65`, `--match-scan 65`, and `--no-extra-shape`.

## Included outputs

- `results/turning_event_continuation.csv`: observed turning clock, drive clock and shifts.
- `results/phase_resolved_events.csv`: raw model coordinates at drive and turning events.
- `results/equal_projection_return_pairs.csv`: exact scalar equal-x roots with unequal posture and triad projector measurements.
- `results/in_ramp_state_rate_curves.csv`: phase-resolved profiles; `results/*.png`: the figures generated by bundled scripts.
- `results/report.json`, `SCIENTIFIC_REPORT.md`, `SCIENTIFIC_DECISION_RULES.md`, Python source, tests, environment, SHA-256 manifest and packaged sendback.
- `inputs/q550_equal_locus_unequal_posture_in_ramp_transport_v18_49w_authenticated_server_sendback.zip`: byte-preserved authenticated Q550 ancestry, including original Python solver.

**Not** a physical clock, body-volume, or material-memory certificate. A near return of one coordinate does not imply closure of a 3D locus.
