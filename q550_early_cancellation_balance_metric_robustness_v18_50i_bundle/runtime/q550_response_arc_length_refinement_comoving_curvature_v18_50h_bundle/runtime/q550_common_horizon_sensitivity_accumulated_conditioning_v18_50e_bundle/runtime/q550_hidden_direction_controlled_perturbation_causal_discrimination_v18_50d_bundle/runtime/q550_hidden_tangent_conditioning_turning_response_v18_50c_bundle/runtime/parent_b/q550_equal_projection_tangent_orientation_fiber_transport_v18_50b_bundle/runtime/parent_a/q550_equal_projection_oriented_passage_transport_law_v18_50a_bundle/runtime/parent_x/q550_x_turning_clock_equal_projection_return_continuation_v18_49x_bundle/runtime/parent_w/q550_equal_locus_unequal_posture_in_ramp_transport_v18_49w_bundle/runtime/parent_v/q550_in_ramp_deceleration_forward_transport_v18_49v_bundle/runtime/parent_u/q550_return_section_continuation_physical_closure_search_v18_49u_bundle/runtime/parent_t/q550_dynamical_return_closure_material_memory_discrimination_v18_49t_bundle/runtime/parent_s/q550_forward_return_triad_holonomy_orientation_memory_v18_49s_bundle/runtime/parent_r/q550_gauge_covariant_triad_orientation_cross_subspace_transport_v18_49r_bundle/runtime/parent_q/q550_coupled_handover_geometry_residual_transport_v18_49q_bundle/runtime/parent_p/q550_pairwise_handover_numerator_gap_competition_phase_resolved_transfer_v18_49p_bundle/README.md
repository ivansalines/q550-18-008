# Q550 v18.49p — Pairwise Handover: Numerator–Gap Competition & Phase-Resolved Transfer Audit

## Scientific target
Test **how** the dominant rank-ordered eigenprojector-generator pair switches from 6–7 to 7–8, after v18.49o bracketed a ramp-duration threshold. Use original Q550 physical 11D and tangent 10D replay in the same fixed kinetic metric and sample both pair channels at registered phases q=0.60…0.65. The ramp shape remains the original equal-area cubic (`beta:2:2`); only the duration changes between independent cases.

Rank pairs are one-based labels: pair 6–7 corresponds to indices (5,6) and pair 7–8 to (6,7). For each pair, `A_ij=2|N_ij/g_ij|²`, with `N_ij=a_j^T Cdot a_i`, `g_ij=lambda_i−lambda_j` and `D_ij=A_ij/sum_{a<b}A_ab`. The numerator's sign is eigenvector gauge-dependent; its absolute magnitude and each A_ij are sign invariant.

**Separate three statements:**
1. A crossing `A_78=A_67` is pair equality.
2. When those two are also the globally top two of all 45 pairs and their ranking exchanges, this is a *global pairwise leadership handover*.
3. An observer-independent physical torsional flip is **not** established by either measurement.

For each duration and κ₀ choice, re-integrate the true 11D return and 10D variational frame. Find sign-bracketed roots by evaluating the same continuous numerical solution (not the ancestor CSV). Verify parent v18.49o and back through v18.49n/m/l/k/j. Log instantaneous `log(A78/A67) = 2 log(|N78|/|N67|) − 2 log(g78/g67)`. Between the endpoints q=0.60 and q=0.65 allocate changes of `A78−A67` to numerator and gap with a symmetric two-factor Shapley identity. This is algebraic allocation, not a causal experiment.

## Scientific boundary
All roots are numerical, not interval-enclosed. Phase points are sampled; unobserved fast or multiple crossings cannot be excluded without further resolution checks. Results depend on the fixed historical kinetic frame and metric. The Shapley split is an algebraic decomposition, not proof that either factor *causes* the physical handover.
