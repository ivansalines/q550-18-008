# Q550 v18.48t — Scientific decision rules

1. **Provenance gate.** All original 11D RHS functions, parameters, signed mechanical energy and historic input states must descend from the exact SHA-pinned original v18.48s **server** sendback, with nested r/q/p/o/j authentication. Never replace them with a qualitatively similar model. An 11D historical forward section mismatch above 1e-7 is a hard failure.
2. **Three independent controls.** Drive rate, programmed duration and turning-point velocity multiplier are imposed inputs. To identify the *rate* effect, hold duration and alpha fixed. To identify the *duration* effect, hold rate and alpha fixed, and distinguish identical shared-clock prefixes from additional accessible future history. To identify the *preparation* effect, hold rate/duration fixed and vary alpha. Seven declared protocol labels include intentionally duplicated overlapping physical histories; count correlations with correct dependence.
3. **Common-clock gate.** An ordinary free-parameter minimum between curves does not suffice for matched-clock recurrence. Constrain `s=1-rate*duration*u`, explicitly exclude the prescribed reversal at u=0, and use one common `q` phase interval for all designs. The external phase is an imposed clock, not an independently measured intrinsic material phase.
4. **Three-dimensional versus full-state gate.** A small 3D shape gap in `(logrho1,logrho2,x)` is **not** a full 11D recurrence. Always report the wrapped material phase and material velocity mismatches and full 11D chart distance at the same corresponding point. No full 11D zero has been certified.
5. **Energy preparation gate.** At intermediate alpha, kinetic energy is changed *instantaneously by the external preparation operation*. The exact kinetic preparation jump must be entered separately in the matched-point mechanical energy ledger. Never report it as work by the ensuing negative clock, nor confuse the signed drive-power term with the net work, entropy production, or a constitutive energy flux.
6. **Same-rate prefix gate.** When only stopping duration changes, solutions at identical *earlier physical time/phase* must coincide to numerical tolerance. This is an important negative control, not evidence of a new rate/duration hysteresis law. Different total excursion allows different endpoints and different search domains.
7. **Boundary gate.** A minimum at the edge of the allowed matched-clock interval is a constrained-domain minimum, not a certified interior crossing. Counts of threshold-persistent points are grid diagnostics; five alpha values do **not** resolve all intermediate bifurcations.
8. **Family/branch gate.** Report phaseblind and phasecov, branches 0/1 and both kappa choices separately; medians over them are descriptive and not iid statistics. The autonomous kappa prescription is distinct from the historical physical calibration kappa0=1/6.
9. **Numerical gate.** Require separately: solver success, four-term energy balance, partial-turn preparation identity, matched-clock energy-gap ledger, original v18.48s alpha-endpoint regression, equal-rate shared-prefix identity, phase match, numerical tolerances and output SHA manifest. Binary64 residual is not rigorous interval certification.
10. **No premature physical law.** The full audit may establish protocol-conditioned near-contact and energy-sign persistence on the **eight sampled Q550 trajectories**. It cannot establish universal hysteresis, intrinsic time asymmetry, thermodynamic irreversible production, or observer-independent torsional geometry without additional controls and proofs.
