# v18.49f — Scientific decision rules

1. **No false cycle.** `phase_span_q/kappa0` close to one is a numerical length
   coincidence until orientated state, transport, and metric-conditioned
   endpoints close independently. Full 10D endpoint angles remain nonzero.
2. **No false lobe.** Only continuous 11D sign-crossing roots count as contact
   boundaries. A tangency or root outside q in [0.2,0.8] does not. Values
   from graphs or interpolation-only threshold crossings are insufficient.
3. **No global threshold-invariant topology.** The two-lobe → one-lobe
   transition is a sublevel-set feature; changes in threshold can merge the
   intervals on the *same* material trajectory.
4. **No false temporal sense.** q increases as the imposed drive's Theta
   decreases. `entry` and `exit` are defined with respect to increasing q;
   slopes against the actual drive clock have opposite sign.
5. **No observer-independent chirality.** A fixed initial metric and 2-plane
   anchored at q=0.35 define signed orientation. Changing that choice can
   change signed angles. The full 10D cosine, cumulative turn and out-of-plane
   leakage are reported to detect misleading 2D projection effects.
6. **Regression and reproduction.** Compare parent E at the exact fixed
   section q=0.50; record max source-orbit error and mechanical ledger
   residual, and verify both kappa0 histories and all embedded SHA members.
7. **Local perturbations are not nonlinear laws.** The variational frame
   transports infinitesimal vectors; pulling back the finite forward-return
   difference creates a useful diagnostic but is not an exact finite-state
   conjugacy or constitutive material equation.
