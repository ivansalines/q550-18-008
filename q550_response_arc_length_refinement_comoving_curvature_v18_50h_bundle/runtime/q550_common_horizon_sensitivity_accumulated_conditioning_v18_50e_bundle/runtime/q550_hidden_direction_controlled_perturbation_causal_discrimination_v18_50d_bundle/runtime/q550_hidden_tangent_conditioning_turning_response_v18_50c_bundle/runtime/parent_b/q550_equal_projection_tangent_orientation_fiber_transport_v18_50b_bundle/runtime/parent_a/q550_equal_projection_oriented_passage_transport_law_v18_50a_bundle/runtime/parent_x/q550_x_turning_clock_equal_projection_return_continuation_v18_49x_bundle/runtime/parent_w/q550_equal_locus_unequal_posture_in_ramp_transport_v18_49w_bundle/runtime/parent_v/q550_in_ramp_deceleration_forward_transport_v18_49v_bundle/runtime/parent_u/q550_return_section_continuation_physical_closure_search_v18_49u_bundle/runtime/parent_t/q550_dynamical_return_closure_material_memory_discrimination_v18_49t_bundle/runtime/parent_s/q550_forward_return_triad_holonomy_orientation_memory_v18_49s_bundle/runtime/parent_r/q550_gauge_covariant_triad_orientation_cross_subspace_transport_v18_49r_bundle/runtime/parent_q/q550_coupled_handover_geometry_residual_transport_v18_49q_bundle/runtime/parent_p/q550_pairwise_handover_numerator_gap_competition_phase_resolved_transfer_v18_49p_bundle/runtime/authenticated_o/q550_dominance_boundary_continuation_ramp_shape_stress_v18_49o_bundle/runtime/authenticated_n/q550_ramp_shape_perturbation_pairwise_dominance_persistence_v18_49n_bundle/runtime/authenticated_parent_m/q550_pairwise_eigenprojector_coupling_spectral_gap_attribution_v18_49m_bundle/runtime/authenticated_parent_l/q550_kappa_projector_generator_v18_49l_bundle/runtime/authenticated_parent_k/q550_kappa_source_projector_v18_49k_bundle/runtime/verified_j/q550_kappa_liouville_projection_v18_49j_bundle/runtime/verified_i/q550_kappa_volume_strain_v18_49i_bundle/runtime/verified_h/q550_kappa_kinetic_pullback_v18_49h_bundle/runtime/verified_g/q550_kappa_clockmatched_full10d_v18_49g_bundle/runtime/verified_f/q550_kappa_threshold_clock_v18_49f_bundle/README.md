# Q550 v18.49f — Threshold-Robust Passage & Clock-Registered Orientation Audit

## Purpose

Revisit v18.49e with seven geometric contact thresholds, six established
smooth reversal ramps, and both documented kappa0 values. Find genuinely
sign-bracketed entrance and exit markers on continuous 11D numerical IVPs,
then characterize the time development of the material difference in a
transported, explicitly metric-dependent **10D common frame**. Avoid identifying
contact interval length with a completed material winding or period.

## Authentic executable genealogy

`inputs/v18_49e_original_server_sendback.zip` is the original server E
sendback, embedded byte-for-byte, SHA-256 pinned by `inputs/SOURCE_PINS.json`.
`scripts/verify_parent.py` validates every E member SHA, extracts it under
`runtime/verified_e`, calls its original parent verifier, and recursively
authenticates E → D → C → B → A → Z → Y → X → W → V → U and earlier
original source code through the J anchor. No ancestor archive is rewritten.
The physical RHS, source model parameters, smoothing schedule, clock, 11D
integrator, coordinate-aware local material difference, and analytic Jacobian
are loaded dynamically from these verified historical Python sources.

## Experiment protocol

- Q550; historical `phaseblind`, branch 0, with `original` and `autonomous`
  kappa0; six ramp durations (xi units): 0.285, 0.292, 0.296333, 0.300,
  0.305, 0.309.
- Full material velocity reversal at turning posture; six smoothstep return
  ramps per kappa0; one original forward run per kappa0.
- Phase coordinate q from 0.2 to 0.8; q advances while drive phase Theta
  decreases with `dTheta/dq = -0.844357915384... rad`.
- Seven thresholds on d3D, where d3D is exactly the parent model's physical
  shape distance: 0.006, 0.008, 0.009, 0.010, 0.011, 0.012, 0.014.
- Candidate extrema are refined before crossing detection; all crossing
  locations are refined with continuous IVP evaluations and Brent's method.
  Contacts are only sign-changing roots, not tangencies or samples crossing
  graph pixels. Re-evaluate roots with a half-density independent q grid.
- A genuine 10×10 tangent fundamental matrix is integrated on each NEW return.
  The local material difference is pulled back to the common frame at the
  turning posture. The initial five-observer family defines the normal
  complement, with Euclidean metric *at that turning posture*.
- A clock-registered oriented 2-plane is anchored at q=0.35, using the residual
  direction and its forward-q derivative. This plane is held fixed across all
  threshold choices for the same physical return. Report projected angle,
  the turning rate, the full 10D angular path length, and off-plane leakage;
  use full 10D endpoint cosine as independent comparison.

## Validated local preflight (floating-point, not interval-certified)

- 14 original 11D integrations, 12 common-frame propagators.
- 242 sign-bracketed oriented marker roots, 121 completed passage intervals,
  36 threshold-independent extrema, 1,212 clock profiles.
- Max original E regression difference 2.61e-13; original orbit difference
  3.44e-13; energy ledger 1.66e-11; clock mismatch zero.
- Max coarse vs fine root deviation 2.23e-13 xi; full 10D turning quadrature
  deviation under doubled sampling 0.00261 degrees.
- At ramp 0.300 and threshold 0.010, contact span is 0.165175 xi
  (0.9911 kappa0) for original, 0.165609 xi (0.9941 kappa0) for autonomous.
  The full 10D *residual-direction endpoint angle* is ~8.39/8.41 degrees,
  while the cumulative direction turning is ~11.50/11.55 degrees. In neither
  case is the transported residual direction closed.
- At ramp 0.300 (original), orientation in the clock-registered plane grows
  from zero at q=0.35 to a local ~15.10 degree peak near q=0.54, then decreases;
  the off-plane fraction reaches ~0.65 by q=0.75. The decrease of the 2D
  projection is not a reversal of the full 10D motion.

## Scientific boundaries

The number of connected subthreshold regions depends on threshold. Their
threshold-independent critical points still depend on the chosen physical
shape coordinates and metric. The transported finite difference between two
finite-separation 11D states is a *linear pullback diagnostic*, not an exact
nonlinear material invariant. The oriented 2-plane is anchored to a declared
clock and a gauge choice; positive/negative projected angle is not intrinsic
chirality. No general kappa0 period, universal material hysteresis law, or
physical closed cycle follows from this audit. Threshold scans and covariance
checks are local numerical experiments, not rigorous interval proofs.
