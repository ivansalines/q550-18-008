# Q550 v18.50c — Hidden-Tangent Conditioning & Turning-Response Audit

This is a reproducible continuation of **authenticated Q550 v18.50b**. The complete authentic parent v18.50b server sendback is inside `inputs/`. It recursively verifies the genuine historical 11D solver and the previous v18.50a event genealogy. Original data and scripts remain unmodified.

## What this experiment asks

When the reduced coordinate `x` reverses direction, does the hidden four-dimensional tangent follow it, remain aligned, or curve while keeping its own transport? How does the *direction* of that hidden tangent change around the dynamically measured x-turn, and how robust is the orientation result to a common metric?

## Run on server

```bash
cd /root/elab1/hysteresis
unzip q550_hidden_tangent_conditioning_turning_response_v18_50c_bundle.zip
cd q550_hidden_tangent_conditioning_turning_response_v18_50c_bundle
bash run_on_server.sh 2>&1 | tee v18_50c_server.log
```

Python 3.13 or any compatible Python 3.11+, NumPy, SciPy and Matplotlib are required. `Q550_PYTHON` selects the interpreter. Use `bash run_on_server.sh --smoke` for the single-case preflight, `--kind original --ramps .24` to select a ramp, `--samples 401` for higher resolution, `--local-window-fraction .3` to test window sensitivity, or `--no-refine` for a quick diagnostic. Complete CLI: `python scripts/run_audit.py --help`.

- `scripts/plot_results.py`, `scripts/generate_report.py`, `scripts/pack_sendback.py` reproduce all figures/report/sendback. The final server sendback contains source, inputs, outputs, hashes, and instructions.
